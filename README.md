# 🚀 Chrome Extension Development Course (with JavaScript)

This repository contains a collection of hands-on projects and educational examples for learning **Chrome Extension Development** using **JavaScript**.

Each **branch** in this repo represents a separate mini project or learning module focused on a specific concept or functionality.

---

## 📚 What’s Covered in the `main` Branch

The **main branch** is dedicated to learning the fundamental structure and core concepts of Chrome extensions, including:

- 🔹 Key extension files and their roles:
  - `manifest.json`
  - `content.js`
  - `background.js`
  - `popup.js`
  - `script.js`
- ⚙️ Working with **Chrome APIs**

## 🧩 Projects (Branches)

Each branch represents a standalone project that builds a functional Chrome extension.

| Branch | Project | Description |
|:-------:|:---------|:-------------|
| `colorFinder` | 🎨 **Color Finder** | Detects and displays color codes (HEX, RGB, etc.) of elements on any webpage. |
| `fontDetector` | 🔤 **Font Detector** | Identifies the font family used in selected webpage elements. |
| `imageDownloader` | 🖼️ **Image Downloader** | Downloads images from any website or open browser tab. |
| `pageTheme` | 🌈 **Page Theme / New Tab Beautifier** | Creates a custom new-tab experience with a visually enhanced layout. |
| `readingTime` | ⏱️ **Reading Time Estimator** | Estimates how long it would take to read an article on a webpage. |
| `site-blocker` | 🚫 **Site Blocker** | Blocks specific websites to help improve focus or limit distractions. |
| `tabRetrieverExtension` | 🧭 **Tab Retriever** | Retrieves and displays a list of all open tabs in the browser. |

---

## 🧠 Purpose of This Repository

The goal of this repository is to provide a practical and structured way to learn **how Chrome extensions work**.

By exploring each branch, you’ll learn how to:

- Understand and build the basic structure of Chrome extensions  
- Use various Chrome APIs effectively  
- Create real, working extensions from scratch

## 📦 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/springtofigh/browser-extension-with-js
   ```
2. Switch to one of the project branches:
```bash
git checkout colorFinder
```

3. Open Chrome and go to:
```bash
chrome://extensions/
```

4. Enable Developer Mode.

5. Click Load unpacked and select the project folder.
